# SVG 国旗核验结果

核验日期：2026-10-02。源代码基线：`ba6157f56946184b81de5d313371a91340168a15`。此次核验没有修改、重新生成或部署旗帜素材。

## 结论

发现了实际源图问题，不能把这套素材整体判为“全部正确”。尼泊尔、毛里塔尼亚、阿森松岛、巴拿马有图案或引用问题；巴哈马、马恩岛、巴布亚新几内亚、圭亚那有不同程度的边缘空隙。圭亚那不同规格的颜色和构图也不一致。

全部文件均可解析并渲染，但渲染成功并不能证明旗帜图案正确。现有 PNG、WebP、AVIF 会继承对应 SVG 的源图问题；此前逐像素转码校验验证的是编码结果与 SVG 渲染一致，并不验证国家旗帜设计。

## 确认的问题

下表路径以 `flags/` 为起点；`apps/php/flags/` 和线上同名文件具有相同问题。

| 代码 / 名称 | 受影响版本 | 具体问题与依据 |
| --- | --- | --- |
| `np` 尼泊尔 | `4x3/np.svg`、`1x1/np.svg` | 下方太阳路径有 32 个交替外/内顶点，即 **16 道光芒**，而官方宪法要求 **12 道**。与外框归一化无关。[官方宪法](https://repository.lawcommission.gov.np/np/category/documents/prevailing-law/%E0%A4%B8%E0%A4%82%E0%A4%B5%E0%A4%BF%E0%A4%A7%E0%A4%BE%E0%A4%A8/constitution-of-nepal/) |
| `mr` 毛里塔尼亚 | `4x3/mr.svg`、`1x1/mr.svg` | 上下红条各占 **15%**，官方规范是 **20%**。当前红/绿/金为 `#cd2a3e` / `#006233` / `#ffc400`，规范为 `#D01C1F` / `#00A95C` / `#FFD700`；月牙和星的大小、位置也与官方图纸不同，应整体调整。[政府视觉规范](https://www.kennach.gov.mr/IMG/pdf/_ar_fr_charte_graphique_mauritanie.pdf) |
| `sh-ac` 阿森松岛 | 两个比例 | 各有 **96 个 `url(#...)` 渐变目标不存在**，文件没有相应渐变定义，导致徽章部分填色缺失。即使上游相同，仍是 SVG 本身的技术缺陷。 |
| `pa` 巴拿马 | `4x3/pa.svg` | 红块从 `y=3.6` 开始、蓝块从 `x=3.2` 开始，露出白边。四区分界为 `x=323,y=225.3`，相对于 640×480 画布的等分中心 `320,240` 有偏差；上下约 46.94%/53.06%。[官方说明和矢量下载](https://www.mingob.gob.pa/simbolosdelanacion/bandera-nacional/)；[上游白边修复](https://github.com/lipis/flag-icons/pull/1440)只处理边缘，并未解决全部几何问题。 |
| `bs` 巴哈马 | 两个比例 | 背景和裁切坐标偏移，顶部未填满。1600px 宽渲染中，方形顶部有 4 行全透明；横版最上行 1597/1600 像素透明。 |
| `im` 马恩岛 | `1x1/im.svg` | 裁切左界落在画布内，1600px 宽渲染有 5 列完全透明的左边缘。 |
| `pg` 巴布亚新几内亚 | `4x3/pg.svg` | 背景路径从约 `x=1.1` 开始，1600px 宽渲染左侧 2 列完全透明。 |
| `gy` 圭亚那 | `4x3/gy.svg`；跨三个版本 | 横版底色从 `x=2.4` 开始，左侧存在微小几何空隙，4096px 宽时有 757 个全透明像素（约 0.0060%）。原比例版与两种比例版的颜色、箭尖位置不同。确认内部不一致，但尚不能宣布其中某组 HEX 是唯一法定正确值。方形本地已有补齐底色的改进，不应覆盖回上游缺口。 |

这些坐标空隙经过高分辨率渲染和路径坐标核对，区别于正常抗锯齿形成的半透明接缝。

### 样式一致性事项

`1x1/sl.svg`（塞拉利昂）设置了 `rx=4.6, ry=7.6` 圆角裁切，导致四角透明。旗帜颜色、横条顺序没有因此出错，但它与大部分方形图标的直角外框不一致，属于小范围样式复核事项。

## 不应直接判为错误的情况

- 4:3、1:1 是本项目明确提供的图标规格。国家旗帜原比例不同，不代表这些图标的外框本身就是错误；尼泊尔非矩形旗形的透明区域也应保留。
- `sy` 叙利亚已使用绿白黑、三颗红星的新版；`kg` 吉尔吉斯斯坦已使用直光芒新版；`mq` 马提尼克已使用红绿黑地区旗。相关核查主要验证明显的新旧设计差异，并非每个线条的生产规格认证。[叙利亚文化部](https://events.moc.gov.sy/about-flag)、[吉尔吉斯斯坦总统府](https://www.president.kg/ru/about/symbol)、[马提尼克行政法院](https://martinique.tribunal-administratif.fr/decisions-de-justice/dernieres-decisions/le-tribunal-annule-la-deliberation-adoptant-l-hymne-ansanm-comme-hymne-de-la-martinique)
- `af` 阿富汗当前文件采用旧共和国三色旗，当地事实政府采用白旗。需要明确产品的版本政策，适合注明版本或并列提供，不宜把它简单归类为绘图错误后直接覆盖。[阿富汗司法部白旗公告](https://www.moj.gov.af/dr/node/4911)
- `hn` 洪都拉斯的深蓝改色是 2026-09-24 的近期提案，核验中没有取得其通过、生效的证据，因此不能据提案把现有青蓝版本判错。[国会提案公告](https://congresonacional.hn/noticias/6ab4834ef02476394afec7bc)
- 圭亚那官方教材的颜色面积表与同页示意图有不一致之处，不能仅按该表直接重画箭头；这里仅报告已经确认的透明空隙和本项目规格间差异。

## 范围与限制

完成了所有 SVG 的结构、引用、尺寸、渲染、文件覆盖、服务器一致性、全套可见图案巡检及上游比较，并对疑点和近期变更做了官方来源复核。没有逐一按全部国家的法定印刷色度、旗帜制造公差或完整纹章母版作认证；未发现其他明显问题，不等于每个细节都已获官方认证。最新上游也包含已确认的源图缺陷，因此不能用“与上游一致”代替图案准确性结论。
